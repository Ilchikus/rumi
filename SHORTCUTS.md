# Rumi Keyboard Shortcuts

Rumi currently supports macOS and Linux.

## Essentials

| Action | macOS | Linux |
| --- | --- | --- |
| Create a page, folder, or database | `Control+N` | `Alt+N` |
| Show or hide the sidebar | `Command+S` | `Ctrl+S` |
| Open or close search | `Command+K` | `Ctrl+K` |
| Close the current menu or dialog | `Escape` | `Escape` |

## Create Menu

Press the Create shortcut or click the **+** button in the sidebar. Page is selected first.

| Action | Shortcut |
| --- | --- |
| Select the previous or next item | `Arrow Up` / `Arrow Down` |
| Select Page | `1` |
| Select Folder | `2` |
| Select Database | `3` |
| Enter a name before creating | `Enter` or click |
| Create immediately with the default name | `Command+Enter` / `Command+Click` on macOS |
| Create immediately with the default name | `Ctrl+Enter` / `Ctrl+Click` on Linux |
| Close the menu | `Escape` |

When you create immediately, Rumi opens the new item with its default title selected. Start typing to
replace the title.

## Writing and Formatting

| Action | macOS | Linux |
| --- | --- | --- |
| Undo | `Command+Z` | `Ctrl+Z` |
| Redo | `Command+Shift+Z` | `Ctrl+Shift+Z` or `Ctrl+Y` |
| Bold | `Command+B` | `Ctrl+B` |
| Italic | `Command+I` | `Ctrl+I` |
| Underline | `Command+U` | `Ctrl+U` |
| Strikethrough | `Command+Shift+S` | `Ctrl+Shift+S` |
| Inline code | `Command+E` | `Ctrl+E` |
| Highlight | `Command+Shift+H` | `Ctrl+Shift+H` |
| Insert a line break without a new block | `Shift+Enter` | `Shift+Enter` |

## Blocks

| Action | macOS | Linux |
| --- | --- | --- |
| Change to paragraph | `Command+Option+0` | `Ctrl+Alt+0` |
| Change to Heading 1 | `Command+Option+1` | `Ctrl+Alt+1` |
| Change to Heading 2 | `Command+Option+2` | `Ctrl+Alt+2` |
| Change to Heading 3 | `Command+Option+3` | `Ctrl+Alt+3` |
| Change to blockquote | `Command+Shift+.` | `Ctrl+Shift+.` |
| Duplicate the current or selected blocks | `Command+D` | `Ctrl+D` |
| Select more blocks | `Command+A` | `Ctrl+A` |
| Move blocks up | `Ctrl+Shift+Arrow Up` | `Ctrl+Shift+Arrow Up` |
| Move blocks down | `Ctrl+Shift+Arrow Down` | `Ctrl+Shift+Arrow Down` |
| Delete selected blocks | `Backspace` or `Delete` | `Backspace` or `Delete` |
| Indent a list item or move to the next table cell | `Tab` | `Tab` |
| Outdent a list item or move to the previous table cell | `Shift+Tab` | `Shift+Tab` |
| Exit a code block | `Command+Enter` | `Ctrl+Enter` |
